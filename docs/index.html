How Study Sprint works

Paste Markdown notes or open a .md file, choose Auto-detect or a study mode, then build your session. Your notes stay in your browser and are not uploaded.

Handwritten notes

Choose Add note photos to recognize up to five JPEG, PNG, or WebP pages (10 MB each) locally. Review and edit the extracted text before building the quiz. The first scan downloads the included English OCR model (about 11 MB); later scans can use the browser cache.

OCR works best with clear, well-lit photos and printed or block handwriting. Cursive and unusual layouts may need manual correction.

Flashcards

Add Q: and A: pairs, or organize notes under headings with short paragraphs and bullet points. Study Sprint turns them into cards. Reveal the answer, then choose to practice it again or continue.

Coding practice

Add a fenced code block with an answer placeholder like {{answer:total}}. Study Sprint hides that word and checks your answer during a 10-minute session. For ordinary code examples, it selects an identifier automatically.

Code is never executed. These tests check the missing text only; they are not a compiler or a substitute for running your assignment.

Build and publish

Run npm install, then npm run dev to work locally. The repository’s GitHub Actions workflow builds and publishes the app to GitHub Pages when changes are pushed to main.
