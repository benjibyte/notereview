# Study Sprint

Turn school notes into flashcards or timed coding practice. Paste Markdown, open a `.md` file, or add photos for local English OCR. Review recognized text before building a quiz.

> **AI note:** This initial version was vibecoded with AI assistance.

## Get started

```sh
npm ci
npm run dev
```

Run tests and build the GitHub Pages site:

```sh
npm test
npm run build
```

See [docs/README.md](./docs/README.md) for Markdown formats, photo OCR details, and publishing instructions. The GitHub Actions workflow in `.github/workflows/pages.yml` deploys the built site when changes are pushed to `main`.
